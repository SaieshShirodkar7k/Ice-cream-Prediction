# 🍦 Ice Cream Sales Predictor

A sleek, responsive Flask web app that predicts ice cream sales based on **temperature** and **rainfall**.  
Styled with a modern **black/grey glassmorphism UI** featuring animations, transitions, and a professional look.

---

## 🚀 Features
- Predict ice cream sales using a trained machine learning model.
- Responsive, animated UI with glassmorphism design.
- Smooth transitions and interactive form elements.
- Built with Flask, scikit-learn, pandas, and modern CSS.
